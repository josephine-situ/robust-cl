\begin{frame}{Method Overview}
    \footnotesize
    \textbf{Problem.} A learned $f(x;\theta)$ is embedded as $f(x)\le b$. Noisy
    labels give models whose ``optimal'' decisions violate the \emph{true} constraint.
    \begin{itemize}
        \item \textbf{Cutting Planes (ours)}: separate the worst-case model over a
              fixed bank of $B{=}200$ relabelings drawn from $D$, one cut per
              iteration. Dial $=\tau$, the stopping tolerance, in sd units.
        \item \textbf{Baselines}: wrapper (chance constraint over $P{=}20$ models,
              dial $\alpha$); RHS margin (shift $b$ by $m\,s_c$);
              C-MICL (split-conformal width model, dial $\alpha$); nominal.
        \item \textbf{Instances}: gastric (OptiCL, 5 toxicity constraints, 96
              held-out arms); DMA-MR reactor (C-MICL Sec.~5.1, \textbf{
              ODE oracle}).
    \end{itemize}
    \textbf{Protocol.}
    \begin{enumerate}
        \item \textbf{Tune} Fix $\rho$; walk each method along \emph{its own} dial;
              report the curve in objective $\times$ feasibility. dial$^\ast$ = best objective
              among cells with feas $\ge0.9$, solved $\ge0.5$. 
        \item \textbf{Evaluate} Re-score at dial$^\ast$ under a judge the dial never faced 
              / on a test set. Different folds of the training set / subsampling are used
              to evaluate the worst-case.
    \end{enumerate}
\end{frame}

\begin{frame}{Implementation details for multiple constraints}
    \footnotesize
    \begin{itemize}
        \item \textbf{Context anchors.} Gastric has one context per study, so
              separation is scored at 10 k-medoid anchors. The protected set is
              \emph{fixed} so all contexts feasible at nominal need to remain
              feasible.
        \item \textbf{Feasibility rollback.} A cut breaking a protected anchor is
              rolled back and that (constraint, draw) pair permanently rejected;
              CP then tries the constraint's \emph{next} most-violating model.
        \item \textbf{Incoherent separation.} Draws are
              ranked \emph{per constraint} and one model admitted for each.
        \item Nothing is ever removed from the master (to prevent cycling).
    \end{itemize}
\end{frame}

\begin{frame}{Next steps}
    \footnotesize
    \begin{enumerate}
        \item \textbf{Freeze the code.} Dials, grids, feasibility target, reactor
              $\rho$ columns; ceiling rows to the appendix.
        \item \textbf{Re-run the gastric dial cell (cluster).} Larger c-micl grid
              --- a strict superset, so no refresh and the scored cells replay
              free. Run the test even if the target is not reached in tuning.
        \item \textbf{Then screen the epigraph objective} (gated on 2). CP at
              the re-run's dial$^\ast$, epigraph on, subsample, CRN-paired
              against the arm already on disk. Nominal holds the best
              realized-OS tail today --- worst of $10$ draws $11.14$ vs CP
              $10.90$ --- so the prize is $0.23$ against a draw sd of $0.55$.
              dial$^\ast$ was tuned with the epigraph off, so the screen is a
              lower bound; escalate to a full sweep only if it moves.
        \item \textbf{Realizations $10 \to 50$.} The tail is the headline; at
              $10$ draws the worst case \emph{is} one draw --- a range, not a
              bound.
        \item \textbf{Reactor: report cost at verified feasibility.} The proxy is
              conservative at the boundary. Measure that gap rather than tighten
              the $0.9$ target.
        \item \textbf{WFP food basket.} Reported by both OptiCL and C-MICL ---
              omitting the shared benchmark reads as selection. Palatability
              label is continuous ($6002 \times 13$), so it enters the regression
              framework unchanged. \emph{One} learned constraint; nutrients are
              known linear, so gastric stays the multi-constraint instance. Open:
              diet reduction vs.\ full supply chain.
        \item \textbf{Synthetic $\to$ appendix.} The reactor's ODE is mechanistic
              truth; synthetic's $f_{\text{true}}$ is authored, on the instance
              where the uncertainty radius and the generated noise are the same
              object.
    \end{enumerate}
\end{frame}
